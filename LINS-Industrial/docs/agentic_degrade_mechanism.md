# 降分机理专诊（ef 证据前移后不掉分反而掉分的根因）

- 日期：2026-08-05
- 复现脚本：`_diag_degrade_mechanism.py`
- 结果：`results/diag_degrade_mechanism.json`
- 前置口径：与 `_probe_evidence_forward_end2end` 完全一致（单轮直答 LLM，base=top-10，ef=top10+整档回捞）

---

## 1. 目的

上一轮 e2e 21 题基线发现：3 道题在“证据前移（ef，加回捞块）”后**确认掉分**（gain=↓）。
本无需弄清：这 3 道题掉分，到底是哪种机理——

1. 补进来的块是**噪声**，被模型误判为正确依据（NOISE_CITED）；
2. 补进了**更多真证据但模型反而没用/失焦**（DISTRACT）；
3. 其他（覆盖度量噪声 / 随机）。

## 2. 实验设置

- 6 题 = 3 道确认降分题 + 3 道对照（1 升分、2 持平）。
- 每题每条件 base / ef 各 **NR=5 次采样**（temperature=0.2），共 **60 次 LLM 调用**。
- 解析模型答卷中引用的 `[编号]` 片段，判定其使用真证据 / 噪声；同时记录 5 次 rule-based 得分。

| 题 | 类型 | 块数(base→ef) | base 均分 | ef 均分 |
|---|---|---|---|---|
| 光纤滤料截污 | 降分 | 10→13 | 1.40 | **1.00** |
| 聚脲防水涂料 | 降分 | 10→33 | 2.80 | **2.20** |
| 插座端子×质量 | 降分 | 10→13 | 3.00 | **2.60** |
| 切削鳞片 | 升分对照 | 10→23 | 0.60 | **2.00** |
| 电压表装配 | 持平对照 | 10→58 | 2.20 | **3.00** |
| 桥式整流器 | 持平对照 | 10→29 | 1.20 | **1.60** |

## 3. 关键发现：`true_evid` 判据在本批全面失灵

脚本用“答案句 vs 块 content 的句级 bigram JT≥0.30”判定某块是否“真证据”，结果**6 题 base 真证据块全部 = 0**、ef 几乎也 = 0（仅切削鳞片 ef 有 1 块）。

原因：standard answer 是**高度压缩的结论句**，检索块是**原文长段落**，两者句级字面重叠天然极低，该判据对这 6 题的召回趋近于零。

> ⚠️ **口径局限声明**：因此基于 `true_evid` 的“噪声误判”自动归因标签（NOISE_CITED）**不可信**，不能用于本批结论。真实机理需依据三样证据交叉判定：
> ① base/ef 得分分布；② 模型实际引用了哪些 `[编号]`；③ 代表答案写得对不对、漏没漏要点。

## 4. 逐题机理判定（基于得分分布 + 引用块 + 代表答案人工核验）

### 4.1 光纤滤料截污（3→2，DEGRADE）
- base 5 次：`1,3,1,1,1`（均 1.4，本身强波动）；ef 5 次：`1,1,1,1,1`（均 1.0）。
- base 代表答案已能写出“截污 2–4 倍、比表面积 3000 m²/m³”并引用 [1][2][4][6]（全在 base top-10）得 3 分的那一次。
- ef 加了 3 块后，仍引用 [1][6][2][4] **同样的块**，却只得 1 分。
- **判定：上下文稀释 / 注意力分散（DISTRACT）**。真证据本就够（base 能得 3 分），新增 3 块让其对同一堆块的表达组织变差 → 稳定掉到 1。base 自身采温 0.2 已有波动，叠加加块干扰后放大器。

### 4.2 聚脲防水涂料（3→2，DEGRADE）
- base 5 次：`3,3,2,3,3`（均 2.8）；ef 5 次：`2,3,2,2,2`（均 2.2）。
- base 与 ef 的代表答案引用的是**同一个正确块 [5]**（水泥基渗透结晶型防水砂浆/速凝型堵漏材料），内容结论一致。
- 同一块，base 多数得 3，ef 多数得 2。
- 块数从 10→33（翻了 3 倍多），新增 23 块多为低相关碎片。
- **判定：上下文稀释 / 分心（DISTRACT）**。加块后对相同正确证据作答质量系统性下降，纯副作用。

### 4.3 插座端子质量控制（3→2，DEGRADE）
- base 5 次：`3,3,3,3,3`（满 3）；ef 5 次：`3,2,2,3,3`（均 2.6）。
- base 代表答案覆盖“端子尺寸、弯曲、接触面、毛刺，**以及过程检验与作业人员自主检验**”
- ef 代表答案（同样引用 [1]）**丢失了“过程检验与作业人员自主检验”这一项** → 得分降。
- 块数 10→13（+3）。
- **判定：上下文稀释 / 要点遗漏（DISTRACT）**。base 证据已完整覆盖答案全部要点，加块后模型反而漏掉其中一项 → 掉分。

### 4.4 切削鳞片（0→2，升分对照）
- base 5 次：`0,0,1,1,1`（均 0.6，base 证据不足）；ef 5 次：`2,2,2,2,2`（均 2.0，全满）。
- ef 答案引用回捞块 [15][11]，给出“积屑瘤 BUE、≥80 m/min、涂层刀片”完整解法。
- **判定：证据缺口型（RECALL GAP）**。base top-10 找不到关键证据，回捞补上后立刻满血——这正是证据前移应该生效的场景：**base 缺证据的题，加块升分。**

### 4.5 电压表装配（2.2→3.0，持平对照）
- ef 5 次全 3（引用 [1]，0.5mm W/S 加宽、开孔需放大）。即便加了 58 块，也没掉分，还升。
- **反证：加块不必然掉分。**

### 4.6 桥式整流器（1.2→1.6，持平对照）
- ef 升到 1.6，未掉。**再次反证：加块不必然掉分。**

## 5. 综合结论

把 3 降分 + 3 对照放一起，分界线非常清晰：

| | base 已能答好（2–3分） | base 证据不足（0–1分） |
|---|---|---|
| 加回捞块后 | **降分**（光纤1.4→1.0、聚脲2.8→2.2、插座3.0→2.6） | **升分**（切削0.6→2.0、电压表2.2→3.0、桥式1.2→1.6） |

> **核心机理：降分主要发生在“base 证据已够、模型已能答好”的题上。`
> 此时证据前移批量回捞进来的低相关碎片把上下文拉长（聚脲 10→33、电压表 10→58），
> 模型对**原本已正确命中的真证据块**注意力被稀释，表现为同一堆块作答质量下降、
> 回答漏掉部分要点（插座端子丢“过程检验”项），从而掉 1 分。**

- **不是**“回捞块是噪声被误判为正确”作主因——降分题里模型引用的仍是 base 就有的真证据块，加块本身没把答案带偏到新噪声上。
- **也不是**“补进更多真证据但没用上”——降分题 base 证据已够，回捞还没带来新的关键证据（切削鳞片才是缺证据的那类）。

### 5.1 对下游的启示（供后续改进）
1. **证据前移要“按需、限量”**：对 base 已能高分（≥2）的题，额外回捞纯属副作用，应设上限或按置信度触发，而非无条件补全整档（voltage 表被补到 58 块是过度）。
2. **对 base 分数较低的题（证据缺口型）才值得大力回捞**——切削鳞片 0→2、多道对照升分都印证这一点。
3. 需要**证据充分性/必要性判据**前置（organizer/planner 判定“当前 top-10 是否已覆盖答案所需要点”），缺才回捞，不缺就不动，才能把 ef 从“平均 0 增益 + 尾部降分”改造成“只增不减”。
4. `standard answer 句级 JT 判真证据` 口径对这类结论型答案不可用，后续评价证据命中应改用：块与整条答案 jaccard / 关键实体 / 答案能由图块的引用得分反推，而不是句级字面重叠。

## 6. 局限
- NR=5 采样对小样本归因足够看趋势，非统计显著；单题判读含人工核验成分。
- `true_evid` 自动判据失灵，本批噪声/真证据只能靠“被引用块 + 得分分布 + 代表答案”三合一交叉判定，未做第二标注者盲评。
- 采样温度 0.2 下 base 自身（如光纤 1,3,1,1,1）有波动，降分幅度（约 0.4–0.8 分）显著大于 base 组内波动，趋势可靠。
